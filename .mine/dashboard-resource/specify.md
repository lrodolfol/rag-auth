# Endoint para dashboard

## Descrição
Após o usuário logar no sistema, ele será redirecionado para o dashboard,
onde poderá visualizar informações sobre o negócio cadastrado.


## Comportamento esperado
- O usuário logado terá acesso a um dashboard com informações relevantes sobre o negócio.
- As informações exibidas são enviadas por esse backend para o frontend.


- Tarefa simples sem complexidade e engenharia excessiva.
